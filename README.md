GameMind 🎮  
Recomendador inteligente de videojuegos según tu estado de ánimo_

GameMind es una aplicación web que recomienda videojuegos basados en cómo te sientes y en lo que quieres aprender o experimentar.  
El prototipo v0 está desarrollado 100% con **React + Vite**, utilizando una **API simulada** para demostrar la lógica del proyecto sin necesidad de un backend real.



Características principales

- Selección de stado de ánimo del usuario  
- Selección de intereses (historia, estrategia, relajante, educativo, etc.)  
- Recomendaciones dinámicas de videojuegos  
- Sistema de valoración: 👍 / 👎  
- Interfaz moderna con un card central  
- API simulada que imita endpoints reales  


¿Por qué GameMind?

Los usuarios suelen perder tiempo buscando qué jugar.  
GameMind soluciona esto recomendando juegos de forma emocionalmente inteligente:

¿Qué juego debería jugar según cómo me siento hoy?

Además, incluye intereses educativos como historia o estrategia.


Tecnologías utilizadas

React
Vite
JavaScript ES6
CSS personalizado
API simulada (Mock API)
